# free window

LSPosed 模块，隐藏 ColorOS / 真我系统自由小窗底部的手势小横条。

## 功能

- 隐藏自由小窗底部的小横条

## 适用系统

- 真我GT5/真我GT8 pro最新系统版本 已测试
- 理论上欧加真所有设备通用，如遇问题请提 Issue或者找酷安作者@时安Halcyon

## 使用方法

1. 安装本模块 APK
2. 在 LSPosed 中启用模块
3. 勾选 **「系统框架」**（android）作用域
4. 重启手机
5. 打开自由小窗，底部小横条已隐藏
