## 📝 说明

- 保留 LSPosed 模块入口（`MainHook`），后续可在此基础上实现新功能（如侧边栏 sidebar）

## 🛠️ 使用方式

1. 安装并启用 LSPosed
2. 安装本模块 APK
3. 在 LSPosed 中勾选作用域
4. 重启勾选作用域应用即可
